# M12 双尺寸桌面卡片

日期：2026-11-13（Asia/Taipei）。

## 交互与兼容

- 桌面小组件列表提供「记一笔 · 2×1 小卡片」与「记一笔 · 4×1 宽卡片」。设置页也提供两个独立添加按钮，由系统桌面确认。
- 2×1 左侧第一行是日消费、第二行是月消费，右侧只有加号，无「记一笔」文字。暖白背景、灰色标签、深色金额；金额按可用空间缩小，特别长的金额省略显示，完整统计保留在卡片内容描述中。
- 4×1 保留原今日／本月两列金额与右侧记一笔入口。两种均以一行高度为目标，仅支持横向调整；实际网格、留白和占格由桌面决定。
- 新增独立小卡片组件，保留原宽卡片组件名，升级不移除已有宽卡片。切换布局需重新添加另一款，拉宽小卡片不会自动切换宽卡片布局。
- 两种卡片任意位置点击都进入记账，复用草稿与金额聚焦逻辑，可同时添加。消费统计只计算正式支出，不将多标签重复计费。

## 刷新

枚举两种组件的全部实例，只读取一次本地统计，再分别生成布局。仅存在小卡片时也能收到保存、删除、回到应用、时间变更等更新；移除其中一种不会取消另一种所需的午夜刷新。没有任何卡片时才取消共享更新。

沿用非唤醒、非精确午夜更新和系统半小时周期刷新。系统省电可能延迟；无新增权限、联网、常驻服务或账本结构变更。
