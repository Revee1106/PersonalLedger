## 基线构建与修复

首次执行 `./gradlew assembleDebug` 时，沙箱拒绝写入用户级 Gradle wrapper 锁文件；按受审提权流程重跑后，Gradle 启动成功，但构建要求 Foojay 下载 Temurin JDK 25.0.3，且网络无法访问下载地址。

检查 `gradle/gradle-daemon-jvm.properties` 后，定位为项目 daemon toolchain 固定写成 `25`，与已安装、项目记录中的 JDK 21 不一致。已将该项目级要求改为 `21`，未调整 AGP、Gradle、SDK，也未修改用户级配置。

修复后实际执行：

```powershell
.\gradlew.bat assembleDebug
```

结果：`BUILD SUCCESSFUL in 3m 45s`，36 项任务执行完成。初始 Debug APK：

```text
E:\PersonalLedger\app\build\outputs\apk\debug\app-debug.apk
```

文件大小 `11,707,930` bytes。M1–M4 完成后会重新构建并更新交付包。
