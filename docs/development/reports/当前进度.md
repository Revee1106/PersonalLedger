# 开发进度

## 当前版本：M12 双尺寸桌面卡片

- 可选 2×1 小卡片和 4×1 宽卡片，应用设置和桌面小组件列表均提供独立选项。
- 小卡片左侧日消费、月消费两行，右侧仅加号；宽卡片保持原布局。共用真实支出统计和刷新，保留已有宽卡片组件及账本。
- Android 14 模拟器实际确认添加框为 2×1／4×1，两款可同时添加、高度一致；仅小卡片时新增12.50后自动刷新，删除测试记录后两款归零。
- Debug 构建、28 项 JVM 和完整32项设备回归已通过；尺寸微调后全部9项卡片专项独立复核通过，无失败或跳过。过程及安装包见 [M12 双尺寸桌面卡片](M12_双尺寸桌面卡片.md)。Lint 为0错误、31警告、4提示。

## M11 历史：单排标签与精简预设

- 首次使用只提供餐饮、交通、购物。其他分类由用户新建，升级保留旧账使用过的标签与自建标签。
- 分类外部为单排勾选，不重复显示已选行和数量。非常用标签按最近选择优先排在最左，常用项顺延，超出宽度可横滑。
- “更多标签”改为底部面板，支持搜索、新建和多选；“编辑常用”支持固定、取消固定、上下排序和独立保存，不按频率自动换位。
- Debug 构建、28 项 JVM 与 29 项 Android 14／API 34 模拟器测试通过，无跳过；Lint 为 0 错误、28 警告、4 提示。详情及安装包校验见 [M11 单排标签与精简预设](M11_单排标签与精简预设.md)。

## M10 历史：多标签与消费平台

- 分类改为多选标签，提供三个按使用情况排序的常用快捷标签，并支持搜索、新建和取消选择。
- 消费平台支持微信、支付宝、淘宝、京东、现金、银行卡，保留原账户 ID 和旧账。数据库 v1 升级为 v2，旧分类自动保留为一个标签。
- 标签金额允许重叠，总收支、预算及桌面消费按账目只计一次；主表单和待确认账单共用选择方式。
- Debug 构建、24 项 JVM 与 24 项 Android 14／API 34 模拟器测试全部通过，无跳过；Lint 为 0 错误、26 警告、4 提示。覆盖旧库升级、标签持久化与统计、多选／新建／取消、金额与平台草稿恢复。安装包及验证边界见 [M10 多标签与消费平台](M10_多标签与消费平台.md)。

## M9 历史：整行统计卡片

- 用户要求卡片保持高度、横向扩展至日历宽度，并显示当日和当月消费。
- 已改为默认 4×1、仅横向调整的暖白卡片，显示今日消费、本月消费与记一笔入口。统计只包含按本地日期归属的正式支出。

- Debug 构建、18 项 JVM 与 17 项 Android 14／API 34 设备测试通过，均无跳过；Lint 为 0 错误、25 警告、4 提示。已实际添加 4×1 桌面卡片，并横向拉满五列，高度不变；记入 12.50 后两项消费合计刷新，删除本次测试记录后恢复零。当前安装包与最终结果见 [M9 整行统计卡片](M9_整行统计卡片.md)。

- 已删除无障碍服务声明、采样服务、内存摘要与解析、设置入口、专属资源和 Probe 构建。保留桌面「记一笔」、草稿恢复、本地账本和通知补充渠道；数据库结构不变。
- 新增两项 Android 回归检查：安装后的 App 不暴露无障碍服务；设置页不再提供付款页面读取入口。移除前两项均实际执行并因旧功能仍存在而失败，记录于检查点 `8c73127`。
- 本轮 Debug 构建通过，10 项 JVM 测试与 14 项 Android 14／API 34 模拟器仪器测试全部通过，均无跳过；Lint 为 0 错误、21 警告、4 提示。最终 APK 已独立检查，不含无障碍服务声明。首次设备回归受到系统无响应弹窗影响，处理后未修改测试便全部通过，详见 [M8 无障碍移除](M8_无障碍移除.md)。下方 M0–M7 内容均为历史阶段记录。
- 已安装的旧 `com.eric.personalledger.probe` 是独立应用；更新主包不会更新该旧包，也不会迁移或删除其账目。当前只构建标准 Debug／Release 主包。
