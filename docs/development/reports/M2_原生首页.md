# M2 原生界面阶段报告

更新：2026-11-11（Asia/Taipei）

## 已实现

- 原生 Jetpack Compose 首页读取所选本地月份汇总、预算、待确认计数和近期账目；首次启动显示空账本。
- 首页按确认稿使用浅色底、本月支出主金额、收入/结余次级金额、月预算进度、待确认入口、最近记录及底部账本/记一笔/统计导航。
- 月度统计按支出/收入切换并展示分类汇总。预算编辑写入本地 SQLite。
- 手动记账表单支持支出、收入、转账，金额使用整数分；支持账户、分类、备注、已有账目更新及确认删除。
- 数据库加载在 IO dispatcher；月份快速切换会取消旧查询，避免过期结果覆盖新月份。
