# M10 多标签与消费平台

日期：2026-11-13（Asia/Taipei）。

## 本次行为

- 一笔账可选择多个分类标签。分类下方提供三个常用标签，点击可选中或取消；点击已选标签的 × 可移除，至少保留一个才能保存。
- “选择标签”面板支持搜索、多选、新建。标签限 1–40 个字符，去除首尾空白、合并重复选择；不能包含控制字符。面板取消不影响表单，新标签随账目保存后进入本地标签库。
- 常用标签按收支类型分别计算，使用已保存账目的使用次数排序，同次数优先最近使用，再按名称稳定排序；不足三个时补默认标签。支出默认餐饮／交通／购物，收入默认工资／奖金／理财。
- 原记账“账户”字段改为“消费平台”，默认提供微信、支付宝、淘宝、京东、现金、银行卡，保留历史自定义账户。仅用于本地分类，不接入或读取这些平台的数据。转账分别选择转出和转入平台，不计入消费。
- 手动新增、编辑及通知候选确认共用标签选择方式。账目列表展示多个标签，统计页说明金额重叠规则。

## 统计口径

一笔 ¥100 同时选择“餐饮”“聚餐”，两个标签各累计 ¥100。总收支、预算和桌面今日／本月消费仍按每笔账计算一次，不把关联表的行数当账目数。标签汇总不能相加作为总消费。

## 旧数据兼容

数据库由 v1 升级到 v2，新增本地标签库和有顺序的账目标签关联表。保留原分类列作为兼容字段，把原分类回填为一个标签；原账目 ID、金额、日期、备注、候选状态、预算和账户 ID 保留。仅以 INSERT OR IGNORE 补充默认消费平台，不重建或清空旧表。

账目和标签在同一事务中新增、修改或确认；无效写入不留下半笔账或孤立的新标签。删除账目时级联移除关联，已创建的标签可继续选择。标签按选择顺序保存；表单采用明确的列表保存规则恢复草稿。
