# M9：整行消费统计卡片

日期：2026-11-13（Asia/Taipei）。用户要求维持现有卡片高度，宽度扩展到整行或与日历等宽，并增加当日和当月消费。

## 布局和统计

- 目标 4×1、保留单行高度，支持横向调整；将最小高度从 72dp 调为 48dp，避免部分桌面按两行分配。旧桌面实例可长按拉宽或重新添加。
- 暖白底、灰色标签、黑色金额；从左到右为今日消费、本月消费、加号与记一笔。去掉截断的应用名，金额自动缩小以适应宽度。
- 统计来自本地正式账目中的支出，整数分计算、按手机当前时区归属日期。收入、转账、待确认与忽略候选不计入；没有消费显示零，读取失败显示破折号。
- 卡片会公开显示两项合计金额，不显示单笔、备注或商户。没有修改数据库结构或迁移既有账目。

## 更新

数据库读取在后台串行执行，避免阻塞广播主线程或旧刷新覆盖新刷新。当前全部正式写账入口（新增、编辑、删除、候选确认）提交后请求刷新，返回应用也刷新。通知采集阶段只生成候选，不更新正式消费合计。

仅存在卡片时读取本月账目、安排下一次本地午夜的非唤醒、非精确更新，并由系统半小时周期更新兜底。开机、时间／时区改变、应用升级后重算；移除最后一张卡片后取消午夜更新。没有精确闹钟权限、无障碍、悬浮窗、联网或常驻服务；普通开机广播权限不弹授权提示。系统后台和省电策略可能推迟刷新，不承诺零点准时更新。
