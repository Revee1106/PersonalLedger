# M11 单排标签与精简预设

日期：2026-11-13（Asia/Taipei）。

## 已确认的交互

- 分类外部只保留一排标签。点击原地改变底色并在右上角显示小勾，不再另放已选行、删除叉号或已选数量。实际可见数量由可用宽度、字体和标签长度决定，超出横向滑动。
- 从“更多标签”选择的非常用标签排在最左侧，最近选择的优先，其余常用项顺延。返回后回到横排起点，方便立即看见新标签；取消非常用项后从外部移除，不改动长期常用设置。
- “更多标签”使用原生底部面板，支持搜索、新建、多选、完成和取消。选择草稿只有完成后回填，账目仍需在主表单保存。未选择任何标签时不能保存账目。
- “编辑常用”可固定最多三个快捷项，也可少于三个或清空；支持取消固定、上移、下移、保存与取消。每种收支类型独立保存，系统不再按记账频率换位。保存失败保留编辑内容并提示重试，不把失败当作成功。
- “保存常用”是独立设置操作，不更改本笔所选分类，不删除标签，不改旧账。新建的标签随账目或常用设置保存后进入本地标签库。

## 初始标签与升级

新安装的标签库和三种收支类型的默认常用项都只有：餐饮、交通、购物。不再预设工资、理财、娱乐、医疗、其他等分类，用户按需自行新建。新通知候选也使用现有默认分类，不引入额外预设；仍需核对后才能入账。

SQLite 数据库升级至 v3，增加按收支类型保存有序常用设置的表。支持 v1 直接升级和 v2 升级，保留原账目、金额、账户关联、日期、备注、预算及标签关联。仅清理没有任何账目引用的旧内置预设名称；历史账目使用过的标签和其他自建名称保留，不清空用户数据。

标签依旧可多选，标签统计允许重叠，总收支、预算和桌面消费按账目只计算一次。
