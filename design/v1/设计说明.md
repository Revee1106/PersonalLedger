# 日常账本 · UI 第一版

暂用名称「日常账本」。这版以暖白、炭黑和灰阶为主，突出金额、分类和确认操作，减少视觉装饰。

## 查看方式

- 用浏览器打开 `index.html`，可切换「核心界面」「登录与提醒」「手机预览」。文件不依赖网络资源。
- `images/01-core-screens.png`：账本首页、记一笔、收支统计。
- `images/02-login-and-reminder.png`：手机号／微信登录入口、支付后提醒。
- `images/03-home.png` 和 `images/04-payment-reminder.png`：单屏预览。

## 页面与交互

| 页面 | 主要内容 | 设计重点 |
| --- | --- | --- |
| 首页 | 月支出、收入与结余、预算、待确认消费、按日排列的账目 | 金额醒目，待确认入口清楚 |
| 记一笔 | 支出／收入／转账、金额、分类、备注、账户、日期、数字键盘 | 减少输入步骤，保存按钮明确 |
| 统计 | 支出／收入切换、每日趋势、分类金额与占比 | 使用灰阶图形，以文字与数值辅助辨认 |
| 登录 | 手机号、验证码、协议、微信登录、本地体验 | 留白充足，主次入口分明 |
| 支付提醒 | 疑似消费、金额、来源、确认／修改／忽略 | 用户确认后入账，并保留修改入口 |

通知画面是系统通知的体验示意；正式显示样式由 Android 版本与手机厂商决定，不能保证逐像素一致。锁屏金额隐藏功能在本稿中仅作说明，尚未接入设置。

## 视觉规范

- 主背景：`#FDFDFB`；主要文字与按钮：`#252623`。
- 辅助背景：`#F1F2EC`；分隔线：`#E8E9E2`；次要文字：`#70716B`。
- 中文使用设备可用的中文字体；数字使用 Bahnschrift，缺失时回退。
- 大金额约 47–49 px，页面标题约 20 px，常规条目约 13 px；原生实现时使用 sp 并适配系统字体缩放。
- 同一套细线图标，分类图形配文字说明；无外部图标与字体下载依赖。
- 使用少量圆角和细分隔线，避免重阴影和多种强调色。

## 已验证与边界

已检查 390×844、360×800、412×915 三种尺寸的五个界面，并验证金额输入、分类与备注、保存后首页和统计更新、收入切换、待确认列表，以及通知确认／修改／忽略和模拟登录流程。

这是可交互的视觉设计原型，使用示例数据。未修改原生 Android 界面，未接入真实账号、短信、支付监听或云端存储。交互数据仅保留在当前页面内存，刷新后重置。账户、日期、历史月份等入口展示交互说明。

登录演示可使用任意格式正确的中国大陆手机号、验证码 `123456`，并勾选协议；不会发送短信，也不会向服务器提交信息。
